## 14.2. Сводка формул

### 14.2.1. Существо

```
mass = chassis.mass + Σ(part.mass) + Σ(upgrade.mass)
maxHp = chassis.hp + Σ(part.hp) + hpUpgrade + round(mass * 0.5)
traction = Σ(part.traction) * (1 + speedUpgrade * 0.04)
vmax = clamp(0.5, 8.0, traction / mass * 2.0)
accel = clamp(2.0, 20.0, traction / mass * 8.0)
turnRate = clamp(90, 720, control / mass * 720)
controlCapacity = Σ(part.control) + controlUpgrade * 8
controlLoad = Σ(part.controlCost) + Σ(weapon.complexity) + behaviorCp * 0.5
maxEnergy = Σ(part.energy) + energyUpgrade
regen = Σ(part.regen)
upkeep = mass * 0.02 + Σ(weapon.idleDrain) + 0.5 + behaviorCp * 0.02
heatGen = Σ(weapon.heat) + sprintHeat + metabolicHeat
cooling = 10 + Σ(part.cooling) + mass * 0.02
armor[type] = min(200, Σ(part.armor[type]) + armorUpgrade * 8)
cost = chassis.cost + Σ(part.cost) + Σ(upgrade.cost) + behaviorCp * 2 + round(mass * 0.05)
```

### 14.2.2. Бой

```
distFactor = clamp(0.4, 1.0, distance / effectiveRange)
evasion = baseEvasion + speed * 0.1 + sizeBonus + coverBonus
hitChance = clamp(0.05, 0.95, accuracy / (accuracy + evasion * distFactor))
armorEff = max(0, armor * (100 - penetration) / 100)
reduction = armorEff / (armorEff + 100)
damage = baseDamage * (1 - reduction) * typeMultiplier * criticalMultiplier
dps = Σ(weapon.damage * hitChance / cycleTime)
effectiveHp = maxHp / (1 - averageReduction)
```

### 14.2.3. Рейтинг

```
newRating = rating + K * (score - expected)
expected = 1 / (1 + 10^((opponent - rating) / 400))
```

Для Glicko-2 используется полная формула с RD и volatility; упрощённая формула выше — только для интуиции.

### 14.2.4. Экономика

```
efficiency = (effectiveHp * 0.6 + dps * 8 + utility * 20) / cost
```

## 14.7. Чек-лист конструктора

- [ ] Выбрано шасси.
- [ ] Есть мозг (ровно один).
- [ ] Есть сердце или метаболический реактор.
- [ ] Есть локомоция (кроме статичных режимов).
- [ ] Все органы в совместимых сокетах.
- [ ] Стоимость ≤ 3000 BM.
- [ ] Энергобаланс не отрицательный.
- [ ] Контроль не перегружен.
- [ ] Есть сенсоры (рекомендуется).
- [ ] Есть оружие (рекомендуется).
- [ ] Поведение валидно.
- [ ] Имя проходит фильтр.
- [ ] Превью читаемо.
- [ ] Тест на полигоне пройден.

## 14.8. Чек-лист армии

- [ ] 1–40 существ.
- [ ] Суммарная стоимость ≤ 6000 BM.
- [ ] Все существа валидны и доступны.
- [ ] Расстановка в зоне развертывания.
- [ ] Нет пересечений.
- [ ] Есть план против ближнего и дальнего боя.
- [ ] Есть защита улья.
- [ ] Есть ответ на рой.
- [ ] Есть ответ на танк.
- [ ] Есть ответ на артиллерию.
- [ ] Проверено на полигоне.

## 14.15. Формат карты

```json
{
  "id": "map_ash_pit",
  "version": "1.0.0",
  "nameKey": "map.ash_pit.name",
  "width": 128,
  "height": 128,
  "tileSizeM": 1,
  "symmetry": "rotational",
  "seed": 918273,
  "layers": {
    "surface": "RLE:GROUND:16384",
    "hazards": "RLE:NONE:16384",
    "cover": "RLE:NONE:16384"
  },
  "hives": [
    {"side": 0, "x": 16, "y": 64},
    {"side": 1, "x": 112, "y": 64}
  ],
  "deployZones": [
    {"side": 0, "x": 8, "y": 54, "w": 16, "h": 20},
    {"side": 1, "x": 104, "y": 54, "w": 16, "h": 20}
  ],
  "resources": [
    {"x": 40, "y": 40, "amount": 5000},
    {"x": 88, "y": 40, "amount": 5000},
    {"x": 40, "y": 88, "amount": 5000},
    {"x": 88, "y": 88, "amount": 5000}
  ],
  "decorSeed": 55123,
  "hash": "b7e2..."
}
```

Правила:

- `surface`, `hazards`, `cover` кодируются RLE для компактности; клиент разворачивает в тайлы.
- Симметрия проверяется сервером.
- Ульи и зоны не пересекаются с препятствиями.
- Ресурсные узлы симметричны.
- `hash` считается от канонического JSON и входит в матч.

## 14.16. Формат описания органа для клиента

```json
{
  "id": "CLAWS",
  "version": "1.0.0",
  "category": "MELEE",
  "socket": "LEFT",
  "sprite": "parts/claws.webp",
  "pivot": {"x": 0.5, "y": 0.5},
  "offset": {"x": 0.35, "y": 0.0},
  "scale": 1.0,
  "z": 40,
  "animation": {
    "idle": {"amplitude": 0.02, "frequency": 1.2},
    "attack": {"windupMs": 180, "releaseMs": 60, "recoveryMs": 220}
  },
  "mirrorable": true,
  "sockets": ["LEFT", "RIGHT"],
  "tags": ["melee", "piercing"]
}
```

- `pivot` — точка вращения в долях спрайта.
- `offset` — смещение относительно сокета в метрах.
- `z` — порядок отрисовки внутри существа.
- `animation` — параметры процедурной анимации.
- Версия описания совпадает с версией органа в каталоге.

## 14.18. Быстрый старт для команды

1. Прочитать `README.md` и `01-концепция.md`.
2. Поднять локальную среду: `docker compose up -d`.
3. Собрать сервер: `./gradlew build`.
4. Запустить `sim-harness` на 100 матчей.
5. Запустить клиент: `npm ci && npm run dev`.
6. Открыть `http://localhost:5173`.
7. Создать тварь из шаблона `SCOUT`.
8. Запустить полигон.
9. Сыграть матч по коду комнаты.
10. Открыть реплей и проверить хеш.
